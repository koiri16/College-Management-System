# College Management System (Core Java)

## 📌 Project Overview
The College Management System is a **console-based application** developed using **Core Java**.  
The main objective of this project is to manage college-related data digitally, such as **students, faculty, and courses**, instead of using manual registers.

This project is designed for **learning Core Java concepts** and understanding how real-world management systems are structured.

---

## 🎯 Key Features
- Add, view, and delete student records
- Duplicate roll number validation for students
- Manage faculty details
- Manage course details
- Menu-driven and user-friendly console interface
- Modular and scalable design

---

## 🧑‍🎓 Student Management
Each student record contains:
- Roll Number (unique)
- Name
- Course
- Department
- Contact Number

Admin can:
- Add new students
- View all students
- Delete students using roll number

---

## 👨‍🏫 Faculty Management
Each faculty record contains:
- Faculty ID
- Name
- Department
- Subject

Admin can:
- Add faculty details
- View faculty records

---

## 📚 Course Management
Each course record contains:
- Course ID (unique)
- Course Name
- Duration
- Department

Admin can:
- Add courses
- View all courses
